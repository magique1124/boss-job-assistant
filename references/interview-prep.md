# 面试准备工作流

触发：用户反馈某个岗位"约面了/要面试了"。目标：针对该岗位 JD + 用户简历，预测面试官可能问的问题、联网补齐资料、进行模拟面试，最后把结果回写投递追踪表。

## 第 1 步：收集材料

1. 从投递追踪表（`投递追踪表.xlsx`）按公司/岗位找到该岗位的 JD 链接；用 `boss detail <security_id>` 或抓取 JD 全文。拿不到全文就用追踪表里的岗位名 + 公司名 + 薪资推断，并向用户要 JD 文本或简历（若之前未提供）。
2. 读用户简历（PDF 用可用工具提取文本；用户未提供则询问）。

## 第 2 步：分析问题面（不联网，先内部分析）

从 JD 提取四个维度，逐维列出可能的问题：

| 维度 | 分析什么 | 问题示例 |
| --- | --- | --- |
| 项目深挖 | 简历项目与 JD 技术栈/业务的重合点 | "你简历里这个项目的 QPS 多少？瓶颈在哪？" |
| 技术八股 | JD 关键词对应的核心知识 | JD 写"熟悉 MySQL 索引"→ 索引结构、最左前缀、慢查询排查 |
| 场景/系统设计 | 岗位级别的常见设计题 | 后端→"设计一个秒杀系统"；运营→"新品 0 预算冷启动" |
| 行为面 | 公司风格与岗位特性 | "为什么离开上一家？""你怎么看待加班/出差？" |

输出《预测问题清单》：按维度分组，每题标注【高频】【可能】【备用】，并给每题 30 秒回答要点（结合用户简历里的真实经历，不要编造用户没做过的项目）。

## 第 3 步：联网查资料（按需）

用搜索补齐三类信息（不要过度搜索，缺什么查什么）：

1. **公司与岗位背景**：公司业务、产品、近期新闻/融资/争议（搜公司名 + "面试"还能看到面经）。
2. **技术面考点**：对 JD 里的关键技术点查最新主流考法（如"Kafka 面试题 2026"）。
3. **面经**：搜 "<公司名> <岗位> 面经/面试"，把高频真题并入清单。

## 第 4 步：模拟面试

和用户逐题演练，规则：

1. 一次只问一题，用户回答后再出下一题。
2. 每轮：用户作答 → 从【扣题度、结构、深度、与岗位匹配】四方面给简短点评和改进版示范回答 → 问"继续下一题 / 这题再来一遍 / 结束"。
3. 覆盖顺序：高频题优先，项目深挖穿插技术题，最后 1-2 道行为面 + 反问环节建议（教用户向面试官提 2-3 个好问题）。
4. 全程不要替用户作答，点评要具体指出哪句好、哪句空。

## 第 5 步：收尾

1. 输出模拟面试小结：整体评分（1-5 星）、最强项、最弱项、考前 3 个建议。
2. 把面试情况回写追踪表：

```bash
python3 <skill目录>/scripts/update_tracker.py 投递追踪表.xlsx update \
  --jd "<岗位链接>" --set 是否约面=是 --set 面试情况="<时间/轮次/结果或待面试>"
```

3. 若用户之后反馈面试结果（通过/未通过/待定），再回写 `--set 面试情况=...`。
